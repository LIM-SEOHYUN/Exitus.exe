## 장르: 2D 탑다운, 서바이벌, 미스터리, 리미널 스페이스
## 엔진: Unity2D 2022.3.44f1
## 언어: C#

## 플레이 방법 (How to Play)
이동은 방향키와 wasd키로 가능합니다.
플레이어는 매 라운드마다 맵을 탐색하며 이상현상(Anomaly)이 발생했는지 관찰합니다.
이상현상이 없다면 정상 루트로, 이상현상이 있다면 회피 루트로 이동해야 합니다.
몬스터(크리처)가 등장하는 이상현상의 경우 플레이어를 추적하며, 닿을 경우 데드 씬(Cutscene)과 함께 라운드가 리셋됩니다.
**연속으로 8번 정답을 맞히면 클리어됩니다.**

## 주요기능
1. 다양한 이상현상 및 도감 시스템
   매 라운드 정해진 확률에 따라 무작위 이상현상이 발생합니다.
   `AnomalyManager`를 통해 중복 발생을 방지하며, 성공적으로 파훼한 이상현상은 도감에 등록됩니다.
2. 크리처 추격 AI
   `CreatureAI`를 통해 플레이어를 감지하고 추적합니다. 크리처는 물리제약을 받지 않습니다.
   단순 추적을 넘어, 플레이어와 충돌 시 VideoPlayer를 활용한 컷씬이 재생되도록 구현하고, 충돌 시 첫 라운드로 돌아갑니다.
3. 직관적인 UI/UX구성
   현재 라운드를 바로 확인할 수 있고, 실패나 성공화면을 띄워 현재 어떠한 상태인지 직관적으로 알 수 있도록 구성하였습니다.
